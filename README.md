# Versionamento

Repositório de exercícios introdutórios de versionamento e colaboração com Git e GitHub, criado durante meus estudos em 2022.

## Arquivos

- `cadastro.txt` — anotação simples sobre cadastro com CPF.
- `login.txt` — anotação simples sobre login com e-mail e senha.
- `.gitignore` — exemplo de arquivo ignorado pelo Git.

## Sobre o projeto

Este repositório registra uma etapa inicial do meu aprendizado sobre controle de versões. Os arquivos de exercício foram mantidos como estavam na época, sem transformá-los em uma aplicação funcional.
