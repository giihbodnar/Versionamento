# Version Control

A repository of introductory Git and GitHub version-control and collaboration exercises, created during my studies in 2022.

## Files

- `cadastro.txt` — a short note about registration using a CPF (Brazilian taxpayer ID).
- `login.txt` — a short note about signing in with an email address and password.
- `.gitignore` — an example of a file ignored by Git.

## About this project

This repository documents an early stage of my learning about version control. The original exercise files have been preserved as they were, rather than turning them into a functional application.
